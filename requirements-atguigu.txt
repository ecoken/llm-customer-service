# atguigu_ai 依赖列表

# ============================================================
# 虚拟环境位置：不要建在项目目录下的 .venv
# ============================================================
# 本项目所在路径本身已接近 120 个字符，而 torch 的头文件
# （torch/include/ATen/native/transformers/cuda/...）还要再叠加约 140 个字符，
# 在未开启长路径支持的 Windows 上（注册表 LongPathsEnabled=0，默认值）会超出
# 260 字符上限，pip 安装 torch 时报：
#     OSError: [Errno 2] No such file or directory: '...predicated_tile_access_iterator_residual_last.h'
#
# 因此虚拟环境建在短路径下，当前使用：
#     D:\venv_ecs
#
# 创建与安装（在 setup.py 所在目录执行）：
#     python -m venv D:\venv_ecs
#     D:\venv_ecs\Scripts\python.exe -m pip install -e . -c constraints-atguigu.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# PyCharm 里把解释器指向 D:\venv_ecs\Scripts\python.exe 即可。
#
# ============================================================
# 版本约束：必须配合 constraints-atguigu.txt 安装
# ============================================================
# 下面的依赖只写了下限，直接安装会拉到 langchain-community 0.4+，
# 而 ecs_demo/addons/information_retrieval.py 依赖的
# langchain_community.graphs.neo4j_graph 与
# langchain_community.chains.graph_qa.cypher 在 0.4 中已被移除，
# 会直接 ImportError。约束文件把 langchain 锁在 0.3.x、neo4j 驱动锁在 5.x。
